# SQL Data Exploration — COVID-19

[Français](#français) · [English](#english)

## Français

### Présentation
Projet d'exploration de données COVID-19 avec SQL Server. Les requêtes analysent les cas, les décès, la population et les vaccinations à différentes échelles, puis préparent des données réutilisables pour des visualisations.

### Travaux réalisés
- Analyse des cas totaux par rapport aux décès
- Analyse des cas par rapport à la population
- Comparaison des taux d'infection entre pays
- Analyse des décès par pays et par continent
- Calcul d'indicateurs globaux
- Jointure des données de décès et de vaccination
- Calcul cumulatif des vaccinations avec une fonction fenêtre
- Utilisation d'une CTE
- Utilisation d'une table temporaire
- Création d'une View pour des visualisations ultérieures

### Techniques SQL utilisées
SELECT · WHERE · GROUP BY · ORDER BY · MAX · SUM · CAST · CONVERT · JOIN · PARTITION BY · CTE · TEMP TABLE · VIEW

### Technologies
**SQL Server** · **T-SQL** · **Data Exploration**
